# HoneyPot

거상 클라이언트(본클라 · 2클라 · 3클라)를 계정별로 실행하고, 게임이 주고받는 패킷을 읽어 서버 접속 · 사통팔달 키워드 ·
개인좌판 체결 같은 일을 알려 주는 프로그램이에요.

> ⚠️ **주의**
> - HoneyPot 은 거상 및 운영사와 관계없는 개인이 만든 비공식 프로그램이에요.
> - 게임 패킷을 읽고 로그인 · 실행을 자동으로 해 주는 기능이 있어서, 게임 운영 정책(이용약관)에 맞지 않을 수 있어요. 사용 전에 운영 정책을 확인하세요.
> - 프로그램 사용으로 생기는 계정 제재 · 손해 등 모든 결과의 책임은 사용자에게 있어요. 프로그램은 있는 그대로 제공되며 어떤 보증도 하지 않아요.

## 기능
- **현황**
  - 클라이언트 카드: 본클라 · 2클라 · 3클라마다 **계정을 고르고 [게임 실행]** 을 누르면 로그인부터 실행까지 해 줘요.
    위의 **▶ 모두 실행** 은 계정을 고른 클라이언트를 차례로 실행해요.
  - 클라이언트 로그: 실행 · 접속 · 공지 · 알림 같은 일이 시간 순서로 남아요.
- **설정**
  - 계정 설정: 게임 계정(아이디 · 비밀번호 · 별명)을 추가 · 수정 · 삭제해요. 예전 거상 스테이션 설정도 가져올 수 있어요.
  - 클라이언트 설정: 서버 · 프리셋, 본클라 · 2클라 · 3클라 폴더, 자동 패치, 심볼릭 다클라, 다클라 생성 · 패치, 게임 창 위치.
  - 알림: 외부 알림(디스코드 · 텔레그램), 알림 창 위치, 알림 소리, 그리고 아래 알림을 하나씩 켜고 꺼요.

| 묶음 | 알림 |
|---|---|
| 서버·접속 | 게임 서버 접속, 게임 끊김, 게임 공지 · 서버 종료 예고(10분 · 5분 · 1분 전), 캐릭터 선택창 이동 예고 |
| 교류 | 사통팔달 키워드, 개인좌판 체결(판매 · 구매 따로) |

알림마다 **앱**(화면 모서리 알림 창 + 클라이언트 로그)과 **외부**(디스코드 · 텔레그램)를 따로 켜고 꺼요.

## 필요한 것
- Windows 10 / 11 (64비트)
- 거상 클라이언트
- **Npcap** (패킷을 읽는 데 필요, 무료): https://npcap.com
  설치할 때 **"Restrict Npcap driver's access to Administrators only" 는 체크 해제**하세요.
- Microsoft Edge · Edge WebView2 런타임 (Windows 10/11 에 기본으로 있어요. HoneyPot 화면과 게임 실행 기능이 씁니다)

## 설치
1. [Releases](../../releases) 에서 `HoneyPot_Setup_v<버전>.exe` 를 받아 실행해요. 관리자 권한은 필요 없어요.
2. Npcap 이 없으면 설치 마지막에 다운로드 페이지를 열어 줘요. Npcap 을 설치한 뒤 HoneyPot 을 실행하세요.
3. 바탕화면(또는 시작 메뉴)의 **HoneyPot** 으로 실행해요. 켤 때 한 번 **관리자 권한 확인창**이 떠요.
   거상 실행기(GersangGameStarter)가 관리자 권한을 요구해서, 여기서 한 번 받아 두면 게임 실행 때 확인창이 다시 뜨지 않아요.

새 버전은 새 설치 파일을 그대로 실행하면 돼요. 계정 · 설정은 그대로 남아요. (자동 업데이트는 없어요)

## 처음 실행했을 때
1. **설정 > 계정 설정** 에서 게임 계정을 등록해요. 비밀번호는 이 PC 의 Windows 사용자 전용으로 암호화(DPAPI)해서 저장해요.
2. **설정 > 클라이언트 설정** 에서 서버를 고르고 본클라 · 2클라 · 3클라 거상 폴더를 지정해요.
3. **현황** 탭의 카드에서 계정을 고르고 **게임 실행** 을 눌러요.

## 외부 알림 (디스코드 · 텔레그램)
설정 > 알림 의 **외부 알림** 칸에서 [디스코드 설정] · [텔레그램 설정] 을 눌러 연결하고, 받고 싶은 알림의 **외부** 스위치를 켜요.

*텔레그램*
1. 텔레그램에서 **@BotFather** 와 대화를 열고 `/newbot` 을 보내요
2. 봇 이름과 아이디(영문, 끝이 `bot`)를 정해요
3. BotFather 가 준 **토큰**(`123456789:ABC...` 모양)을 [텔레그램 설정] 칸에 붙여 넣어요
4. 텔레그램에서 방금 만든 봇과 대화를 열고 **[시작]** 을 누르거나 아무 말이나 보내요
5. **[연결 확인]** 을 누르면 그 대화방을 찾아 시험 알림을 보내요

*디스코드*
1. 알림 받을 채널의 ⚙ 채널 편집 › 연동 › 웹후크 › 새 웹후크 › **웹후크 URL 복사**
2. [디스코드 설정] 칸에 붙여 넣고 **연결** (연결하면 시험 알림이 가요)

여러 PC 에서 한 곳으로 받으면 **PC 이름** 을 PC 마다 다르게 정해요. 메시지가 `PC이름 · …` 로 시작해요.
웹후크 주소와 봇 토큰은 이 PC 의 Windows 사용자만 풀 수 있게 암호화해서 저장하고, 화면에는 끝 네 글자만 보여요.
봇 토큰 · 웹후크 주소는 남에게 알려 주지 마세요.

## 데이터
- 프로그램: `%LOCALAPPDATA%\Programs\HoneyPot`
- 계정 · 설정 · 로그: `%LOCALAPPDATA%\HoneyPot`
- HoneyPot 은 게임 데이터를 다른 곳으로 보내지 않아요. 인터넷은 게임 실행(거상 홈페이지 로그인 · 패치)과
  사용자가 켠 외부 알림(디스코드 · 텔레그램)에만 써요.

## 제거
Windows 설정 > 앱 에서 HoneyPot 을 제거해요. 계정 · 설정까지 지울지는 제거할 때 물어봐요.

## 문제 해결
- **패킷 수집 꺼짐**: Npcap 이 설치되어 있는지, 관리자 전용 설정으로 설치하지 않았는지 확인하세요.
- **백신이 막음**: Python 으로 만든 프로그램이라 일부 백신이 의심할 수 있어요. 이 저장소 [Releases](../../releases) 의 설치 파일만 사용하세요.
- **설치 확인**: 명령 프롬프트에서 `HoneyPot.exe --selftest` 를 실행하면 `%LOCALAPPDATA%\HoneyPot\selftest.txt` 에 점검 결과가 남아요.
- 오류가 나면 `%LOCALAPPDATA%\HoneyPot\honeypot.log` 를 확인하세요.
